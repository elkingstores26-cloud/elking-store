تحرير المنتج

دوس على لون من الليستة، أو اكتب اسمه واختار اللون من الزرار اللي على الشمال.
سيبه فاضي لو مفيش خصم. لما تملاه، شارة "خصم ٪" بتظهر تلقائياً.
اللي بتكتبه هنا بيظهر في صفحة المنتج وكسطر مختصر تحت الموديل في صفحات الليستة.
المنتجات المختارة بتظهر في قسم "عروض اليوم" أول ما حد يفتح الموقع.
المنتجات الغير متوفرة بتظهر باهتة على الموقع وزرار الطلب بيتعطّل.
لو نفس الموبايل بألوان مختلفة وكل لون له سعر — ضيفهم هنا. العميل يقدر يختار اللون من صفحة المنتج ويشوف السعر بيتغيّر.

إعدادات النشر المباشر

📌 إزاي تجيب الـ Token؟
  1. افتح: github.com/settings/tokens?type=beta
  2. اضغط Generate new token
  3. الاسم: El King Admin
  4. Expiration: No expiration (أو زي ما تحب)
  5. Repository access: Only select repositories → اختار elking-store
  6. Permissions → Repository permissions → Contents: Read and write
  7. اضغط Generate token ← انسخ الـ token اللي يبدأ بـ github_pat_...
  8. الصقه تحت ⬇️
الـ token بيتحفظ على جهازك بس (في الـ browser) — مش بنبعته لأي حد غير GitHub.
